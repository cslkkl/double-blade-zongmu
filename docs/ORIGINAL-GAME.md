## 1. 剧情设定

- **背景**：古希腊时代，公主被神话怪物掳走，两名斯巴达风格的勇士出发闯关救公主。
- **主线**：玩家一路穿过黄金王国、神殿遗迹、迷宫、冥界洞穴，依次击败6名神话BOSS。
- **反转结局**（双人模式特有）：击败最终BOSS独眼巨人、救出公主后，剧情强制要求两名**玩家互相厮杀，其中一人被打死**才能真正通关——合作通关后立刻进入"战友对决"，是该游戏最知名的反套路设计。
- **单人模式**：无此对决环节，直接救出公主结算。

## 2. HUD 界面

- **左上角**：玩家1血条（黄色）+ 能量条（绿色，盾牌图标旁）
- **左中**：玩家2血条 + 能量条
- **右上角**：当前关卡头盔图标 / 剩余敌人进度提示
- **血条**：受击减少，归零死亡；关卡间不自动回满，需靠道具或关卡内恢复点
- **能量条**：攻击敌人、受击会积攒，攒满后释放旋风斩

## 3. 操作说明

### 3.1 按键映射

| 动作 | 玩家1 | 玩家2 |
|------|-------|-------|
| 左右移动 | ← → | A D |
| 上下（下蹲/对上下层平台） | ↑ ↓ | W S |
| 攻击 / 对话 / 拾取武器 | `<` 键（逗号） | `G` 键 |
| 跳跃 | `>` 键（句号） | `H` 键 |
| 旋风斩（特殊技） | 攻击 + 跳跃 同时按 | G + H 同时按 |

### 3.2 动作细节

- **攻击**：手持武器时朝面朝方向挥砍；空手时出拳（伤害极低）。
- **拾取武器**：走到地面掉落的武器上，按攻击键拾取；**手上已有同类武器时无法拾取**（需先扔掉/打烂手里的）。
- **投掷**：手持可投掷物（石块、雕像、母鸡、野猪等）时，按攻击键会朝面朝方向扔出，远程伤害BOSS。
- **旋风斩**：能量满后触发，角色原地旋转范围攻击，对周围所有敌人造成高额伤害并带无敌帧，是清场/对BOSS主力技能。
- **骑乘**：靠近可骑乘动物（野猪、老虎）按攻击键骑上，移动速度和攻击力提升；再按攻击键跳下。
- **受击硬直**：被敌人打中会后退并掉血；双人模式下**队友的攻击也能命中自己**——可以把队友手里的武器震掉。

---

## 4. 玩家角色

- **玩家1**：红色顶盔羽饰的斯巴达勇士。
- **玩家2**：黑色/深色顶盔羽饰的斯巴达勇士。
- 二者属性、武器、技能完全一致，仅外观颜色不同。
- 角色比例Q版大头短身，Nitrome标志性像素动画。

## 5. 场景与关卡结构

### 5.1 三大主题区域

| 区域 | 主题 | 环境特征 |
|------|------|----------|
| 第一区域：黄金王国/郊野 | 古希腊户外 | 橄榄树、土黄色地面、树桩、远山，色调偏暖黄 |
| 第二区域：神殿遗迹/迷宫 | 石砌建筑、迷宫 | 石柱、祭坛、机关、室内昏暗光 |
| 第三区域：冥界/洞穴 | 骷髅、枯骨、碎石 | 暗色调，骷髅兵与巫师出没，地面有坑洞 |

### 5.2 12关分布（普通关与BOSS关交替）

按 Nitrome 官方设定，3个主题各4关，BOSS分布为：

| 关号 | 类型 | 内容 |
|------|------|------|
| 1-1 | 普通 | 郊野杂兵教学 |
| 1-2 | 普通/精英 | 第一批弓箭手、野猪出现 |
| 1-3 | **BOSS** | 黄金国王米达斯 |
| 1-4 | 过渡普通 | 神殿入口 |
| 2-1 | 普通 | 狮头锤首次掉落（仅3.1关前后） |
| 2-2 | **半BOSS** | 海格力斯（Hercules） |
| 2-3 | **BOSS** | 牛头人弥诺陶洛斯 |
| 2-4 | 普通 | 迷宫深处 |
| 3-1 | 普通 | 冥界骷髅兵、巫师 |
| 3-2 | **BOSS** | 青铜巨人塔罗斯 |
| 3-3 | **BOSS** | 美杜莎 |
| 3-4 | **最终BOSS** | 独眼巨人（Behemoth） |

> 注：具体关号顺序以实际游戏为准，核心是"3主题、6BOSS、半BOSS+全BOSS交替推进"。

## 8. BOSS 全图鉴

### 8.1 黄金国王 米达斯（Midas）
- **出处**：希腊神话中点石成金的国王。
- **招式**：
  - 朝玩家奔跑并大喊"**Hug me!（抱抱我）**"——被他碰到会被变成黄金并掉血。
  - 把场景中的动物/道具点成金色雕像。
- **弱点/打法**：
  - **不要近身**，用投掷物（石头、雕像、母鸡）远程砸他。
  - 被点成金雕像的队友/动物可以捡起当投掷物。

### 8.2 海格力斯（Hercules / Heracles）
- **定位**：半BOSS（mini-boss），强力格斗型杂兵首领。
- **招式**：近战连击、冲撞。
- **打法**：保持距离，用弓箭或旋风斩处理。

### 8.3 牛头人 弥诺陶洛斯（Minotaur）
- **出处**：克里特迷宫牛头怪。
- **招式**：低头横冲直撞。
- **弱点/打法**：
  - 冲撞时会**把牛角卡进石柱里**，动弹不得，是输出窗口。
  - 往两侧躲闪，等他撞柱子后上去猛砍。

### 8.4 青铜巨人 塔罗斯（Talos）
- **出处**：希腊神话青铜巨人，对应"阿喀琉斯之踵"梗。
- **特征**：体型巨大，画面里只能看到他的**腿和脚**，上半身在屏幕外。
- **招式**：跺脚、踩击玩家。
- **弱点/打法**：
  - 唯一弱点是**后脚跟/脚踝**。
  - 等他抬脚落地时，跳起来攻击他的脚后跟。

### 8.5 美杜莎（Medusa）
- **出处**：蛇发女妖，看她眼睛会被石化。
- **招式**：
  - 用弓箭射击玩家。
  - **尖叫石化**：与她视线接触时玩家会逐渐变成石头。
- **应对**：
  - **全程背对她移动**，不要让屏幕朝向与她对视。
  - 若被石化，**快速连续按左右方向键**挣脱。
  - 石化过程可以被打断。

### 8.6 独眼巨人 比希摩斯（Behemoth / Cyclops）
- **出处**：奥德赛中的独眼巨人。
- **招式**：
  - **吐石块**：朝玩家方向投掷岩石。
  - **抓人**：近身抓起玩家。
- **弱点/打法**：
  - 等他攻击后**打晕他**，跳起来攻击他的**独眼**。
  - 这是最终BOSS，击败后触发结局。

## 9. 特殊机制汇总

| 机制 | 触发条件 | 效果 |
|------|----------|------|
| 旋风斩 | 能量条满 + 同时按攻击跳跃 | 范围旋转高伤害，带无敌 |
| 石化 | 与美杜莎对视 | 玩家变石头，快速左右按键挣脱 |
| 点金 | 被米达斯碰到 | 玩家变金雕像掉血，死亡后掉金雕像 |
| 武器耐久 | 连续挥砍 | 武器损坏消失 |
| 队友互伤 | 双人模式下队友攻击 | 可打断队友、震掉其手中武器 |
| 骑乘 | 靠近野猪/老虎按攻击 | 提升移速和攻击 |
| 投掷 | 手持可投掷物按攻击 | 朝面朝方向扔出 |
| 隐藏结局 | 双人模式通关最终BOSS | 两玩家必须互殴死一人才能救公主 |

## 10. 胜负条件

### 胜利
- 单人：打完12关、击败独眼巨人、救出公主。
- 双人：打完12关后，在结局对决中打死另一名玩家，救出公主。

### 失败
- 任一玩家血条归零即死亡；双人模式下若两人都死亡，关卡重来。
- 无敌版（改版）血条锁定，不会因敌人攻击死亡；但**最终双人互杀环节会因为双方都不掉血而无法触发结局**，属于改版副作用。

## 12. 核心设计特点（为何经典）

1. **打击感扎实**：Nitrome招牌动画，武器挥动有轻重之分。
2. **武器丰富**：近战/远程/投掷/坐骑，道具恶搞（母鸡、雕像）。
3. **双人合作+互坑**：既能并肩作战，也能把队友武器打飞。
4. **神话BOSS有梗**：每个BOSS都对应一个希腊神话知识点（阿喀琉斯之踵、点石成金、美杜莎石化、米诺陶诺斯撞柱）。
5. **反套路结局**：救公主前先杀队友，童年回忆杀。
