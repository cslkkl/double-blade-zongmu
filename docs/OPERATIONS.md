# 操作与键位 — 唯一口径

键位的**行为判定**在 [index.html](../index.html) 的 `startGame()` 与 `readPad()`，
**展示文案**在 [js/guide.js](../js/guide.js) 的 `PAD_LEGEND` / `KBD_LEGEND` / `HINT_KBD`。
本页是这两处的对照表与改动清单；别处不再另抄一份键位表。

## 一、设计口径

- **一个动作一个键**。同一个动作不存在「`F` 或 `J`」这类同义多键，也不存在「跳 + 攻同按」这类复合手势。
- **键盘与手柄逐条对应**。两边都是「移动 + 挥刀 + 跳 + 旋风斩 + 拾取 + 递给 + 丢弃 + 暂停」，行序一致。
- **两名玩家各占一块**。玩家一左手区（`A` `D`）+ 右手 home 行（`J` `K` `L`）；玩家二左手方向键 + 右手小键盘。
- **高频在 home 行，低频抬一格**。挥刀/技能/拾取在 `J` `K` `L`，递给/丢弃在 `U` `I`。
- **两套键码表严格不相交**。`keyPressed()` 会消费按下标记，共用一个键就会被一方吃掉。
- **拾取与攻击必须分开**。合成一个键时，站在掉落物旁边一按就先拾取、把这一刀吃掉。

## 二、键盘

| 动作 | 玩家一 | 玩家二 | 判定 |
|---|---|---|---|
| 左右移动 | `A` / `D` | `←` / `→` | 按住持续 |
| 挥刀 · 连按三连 | `J` | `小键盘 4` | 按下沿 |
| 跳跃 | `W` | `↑` | 按下沿 |
| 旋风斩 · 能量满时 | `K` | `小键盘 5` | 按下沿 |
| 拾取 / 开箱 / 换手 | `L` | `小键盘 6` | 按下沿 |
| 递给队友 | `I` | `小键盘 8` | 按下沿 |
| 丢弃手上武器 | `U` | `小键盘 7` | 按下沿 |

小键盘按**物理位置**判定（`e.code` 是 `Numpad4` 这类），`NumLock` 开着关着都是同一颗键。
`NumLock` 关闭时 `Numpad7/9/1/3` 会退化成 `Home` / `PgUp` / `End` / `PgDn`，`index.html` 因此对所有 `Numpad*` 一律 `preventDefault`。

**单人模式**：玩家二不存在，方向键与小键盘整套并给玩家一 —— 习惯「方向键走位」的玩家不会一个键都不响。

## 三、手柄

两把手柄各控一人（按连接顺序分配：第 1 把 → 玩家一，第 2 把 → 玩家二）。

| 操作 | 按键 | 编号 |
|---|---|---|
| 左右移动 | 左摇杆 / 十字←→ | 轴 ±0.42 · 14 / 15 |
| 挥刀 · 连按三连 | `A`（Xbox）/ `×`（PS） | 0 |
| 跳跃 | `X`（Xbox）/ `□`（PS） | 2 |
| 旋风斩 · 能量满时 | `B`（Xbox）/ `○`（PS） | 1 |
| 拾取 / 开箱 | `Y`（Xbox）/ `△`（PS） | 3 |
| 递给队友 | 十字 ↑ | 12 |
| 丢弃手上武器 | 十字 ↓ | 13 |
| 暂停 / 继续 | `Start`；`Back` 同义 | 9 / 8 |

只插一把手柄时手柄归玩家一（含全部动作键）；「两人共用移动方向」是旧说法，动作键从不共用。

## 四、触屏

虚拟键是独立输入通道，不模拟键盘事件（模拟会让设备判定切回键盘，手机玩家会看到「按 J 挥刀」）。

| 左半屏 | 右半屏 |
|---|---|
| `◀` `▶` 移动 · `跳` | `刀`（主键，最大）· `技` · `拾` · `丢` · `递` |

顶栏另有 `❚❚` 暂停与 `?` 键位说明。布局表在 [js/touch.js](../js/touch.js)，与 `js/guide.js` 的 `TOUCH_LEGEND` 逐字一致。

## 五、覆盖层与页面

每个可交互界面都必须键盘、手柄、触屏三条输入都通 —— `readPad()` 只在 `play` 阶段被调用，离开对局就没人读手柄。

| 页面 | 键盘 | 手柄 | 触屏 |
|---|---|---|---|
| 标题页 | 任意键 | 任意键 | 点屏幕 |
| 模式选择 | `1` 或 `小键盘 1` 单人 · `2` 或 `小键盘 2` 双人 | `A`/`X` 直选单人 · `B`/`Y` 直选双人 · 十字←→ 移高亮 · `Start` 确认 | 点按钮 |
| 开场短片 | 长按 `空格` / `Esc` 0.7 秒跳过 | 长按 `A` / `Start` | 长按屏幕 |
| 暂停页 | `Esc` 继续 · `R` 重开 · `H` 键位 | `Start` / `A` / `B` 继续 · `Y` 重开 | 点屏幕 |
| 结算页 | 任意动作键（等 0.4 秒 + 先松开） | `A` / `B` / `Start` | 点按钮 |
| 键位抽屉 | `H` 开合 · `Esc` 关 | `Back` 开合 · `A`/`B`/`Y`/`Start` 关 | 顶栏 `?` |

所有覆盖层的手柄边沿都带**启用闸**：先见到一次全部松开才受理，否则「打开它的那一下还按在手上」会当场确认掉。

## 六、改键位要同步的六处

漏一处的症状都是「文档说按某键，按了没反应」。

| # | 位置 | 改什么 |
|---|---|---|
| 1 | `index.html` `startGame()` | 两张键码表（含单人附加） |
| 2 | `index.html` `KEY_LABEL` | 拾取气泡里的键名文案 |
| 3 | `index.html` `INTRO_KEYS` | 短片跳过白名单 |
| 4 | `index.html` `CONFIRM_KEYS` | 结算页确认闸白名单 |
| 5 | `js/guide.js` `KBD_LEGEND` / `HINT_KBD` | 键盘图例 + 底部提示条 |
| 6 | 本页与 [README.md](../README.md) 的键位表 | 对外口径 |

改了 `js/` 下任何文件，记得把 `index.html` 里 script 标签的 `?v=` 版本号 +1。
