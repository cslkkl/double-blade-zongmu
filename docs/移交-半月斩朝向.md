## 关键数值

三张通用刀光素材**凸背朝左、凹口朝右**，即「(` 形」。

| 素材 | 尺寸 | 弧心 `cx/w` | 弧心 `cy/h` | 脊线半径 `R/w` | 最厚点位置 |
|---|---|---|---|---|---|
| `assets/slash-1.webp` | 122×400 | 1.025 | 0.481 | 0.871 | 0.149 |
| `assets/slash-2.webp` | 159×400 | 0.857 | 0.486 | 0.660 | 0.184 |
| `assets/slash-3.webp` | 297×400 | 0.652 | 0.487 | 0.405 | 0.233 |

- 「最厚点位置」= 最厚点在自己宽度上的归一化坐标，0 = 最左，1 = 最右。
- 「弧心」= 按行取最长游程中点当脊线，再对脊线做最小二乘圆拟合（Kåsa 法）得到的圆心。
- 完整测量与武器专属弧光表见 [依据-半月斩素材左右不对称](../.agents/notes/依据-半月斩素材左右不对称.md)。

两条硬结论：

- 旧代码 `ox = -dw * 0.42` 是「按包围盒居中」，与真实弧心（0.652~1.025）不符，月牙亮肚落在握柄后方。
- `facing < 0` 只做整体 `ctx.scale(-1,1)`，不做形状修正，朝左时月牙被镜像成「)」形。

## 工具坑

- 探针页必须紧跟 `<meta charset="utf-8">` 后加 `<base href="../">`，否则 `js/*` 与 `assets/*` 全部 404。
- `file://` 页面 `getImageData` 抛 `SecurityError`（canvas 被跨源污染）；要测像素必须起本地 HTTP 服务。
- **浏览器缓存 `js/*.js`** —— 改完代码要换端口重开服务，否则测到的是旧代码。本轮踩过一次，用旧代码的结论判断了新代码。
- 探针必须先 `await Assets.load()` 再调 `FX.drawSlash`，否则 `FX.ready()` 为假、落到纯代码降级路径，测不出素材行为。
- 多个 agent 共用同一个 Playwright 实例；回归证明落到 `tools/*.mjs` 的 mock canvas。
