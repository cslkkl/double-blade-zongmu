# .agents/notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。目录结构与去哪查见 [README.md](README.md)。

- 第 3 行必须是状态行，四值之一：`状态：生效` / `状态：被取代` / `状态：已否决` / `状态：已归档`。
- `被取代` 紧跟指针行指向取代它的笔记；`已否决` / `已归档` 紧跟一句话理由。
- 决策类命名 `YYYY-MM-DD-<主题>.md`，必含 `## 替代方案（强制）`；依据类可省日期，`## 支撑的决策` 有下游才写。
- 归档就地标记，不建 `archived/` 子目录；不建索引文件，不逐篇列清单。
