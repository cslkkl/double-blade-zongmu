# .agents/notes/ — 决策与依据记录

非活文档层：记录「当时为什么」，不随代码演进追改。
现在是什么看 [../../docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md)；文件职责与变更路由看 [../../js/README.md](../../js/README.md) 与 [../../tools/README.md](../../tools/README.md)。

## 目录结构

```
.agents/notes/
├── AGENTS.md          # 规则层：状态标记、命名、归档
├── README.md          # 本页：结构与去哪查
├── YYYY-MM-DD-*.md    # 决策类
└── 依据-*.md          # 依据类（可省日期）
```

不建 `archived/` 子目录，不建索引文件。

## 两类怎么分

| 类型 | 触发源 | 命名 | 必备节 |
|---|---|---|---|
| 决策类 | 做选择：在几个方案里挑一个 | `YYYY-MM-DD-<主题>.md` | `## 问题` / `## 决策` / `## 替代方案（强制）` / `## 影响` |
| 依据类 | 做调查：看事实、对照、下判定 | `依据-<主题>.md` | `## 背景` / `## 结论` / `## 影响` |

- 判据只有一条：这次是「做选择」还是「做调查」。
- 调查结论喂给某个决策时，依据类写 `## 支撑的决策` 指回决策类，不复制决策内容。
- 决策类必须在第 3 行给状态：`生效` / `被取代` / `已否决` / `已归档`。

## 去哪查

- 想知道某条硬约束为什么存在 → 读对应决策类的 `## 问题` 与 `## 替代方案（强制）`。
- 想知道某次排查看到了什么 → 读依据类的 `## 结论`。
- 想知道这条记录还成立吗、什么条件下过期 → 读每篇的 `## 影响`。
- 想确认某条记录是否已被推翻 → 看第 3 行状态和紧随的指针 / 理由行。
- 想知道某次事故的根因 → 不在本目录，见 `docs/postmortem/`（按需创建）。

## 维护

- 决策反转不就地覆盖：新写一篇，并把旧篇改 `状态：被取代` + 指针行。
- 事实性变化（路径、默认值、机制名）就地更新，状态不变。
- 新记录只写代码与提交里查得到的事实，数字先量再写。
- 写完跑根 [../../AGENTS.md](../../AGENTS.md) 的链接校验命令。
