# 双刃战士 · 纵目

> 三星堆青铜人头像主题的**双人同屏横版清版动作游戏**。
> 单页应用，零依赖，断网可运行，支持两把游戏手柄。

东莞市博物馆 × 碳基社区「AI 创作者进馆计划」参赛作品（AI 编程赛道）。

![游戏画面](docs/screenshot.webp)

---

## 这是什么

4399《双刃战士》（Nitrome, 2011）那一类玩法：两个人挤在一台电脑前，各握双刃，一路砍过去，捡武器、打连击、放旋风斩。

主角换成了 **三星堆八号祭祀坑出土的青铜人头像**——这张脸被从土里挖出来，现在站起来，手里握着两把刀。

## 怎么玩

双击 `index.html`，用浏览器打开。
按任意键进入**单双人模式选择**：按 `1` 单人独守，按 `2` 双人同屏。
不需要联网，不需要安装任何东西，不需要本地服务器。

### 键盘

| 动作 | 玩家一 | 玩家二 |
|---|---|---|
| 左右移动 | `A` / `D` | `←` / `→` |
| 跳跃 | `W` 或 `空格` | `↑` 或 `右 Shift` |
| 挥刀 · 连按三连 | `F` 或 `J` | `/` 或 `小键盘 0` 或 `K` |
| 拾取 / 换手 | `G` | `;` |
| 丢弃手上武器 | `E` | `.` |
| 递给队友 | `R` | `'` |
| 旋风斩 | 能量满时 跳 + 攻击 同按 | 能量满时 跳 + 攻击 同按 |
| 暂停 | `Esc` | `Esc` |
| 按键说明 | `H` | `H` |
| 静音 | `M` | `M` |

> 挥刀与拾取是两个键：刀只管打，捡东西按 `G` / `;`。武器只有手上那一把，捡到好的直接换手，旧的落回原地。

### 手柄

两把手柄可各控一人，插上按任意键即被识别。识别到手柄后，界面上的键位会整体换成手柄版 —— 键盘与手柄两套永不同时出现。

| 操作 | 按键 |
|---|---|
| 左右移动 | 左摇杆 / 十字键左右 |
| 挥刀 · 连按三连 | `A`（Xbox）/ `×`（PS） |
| 跳 | `X`（Xbox）/ `□`（PS） |
| 旋风斩（能量满） | `B`（Xbox）/ `○`（PS） |
| 拾取 / 开箱 | `Y`（Xbox）/ `△`（PS） |
| 换武器格 | `LB` / `RB` |
| 递给队友 / 丢弃 | 十字上 / 十字下 |
| 暂停 / 继续 | `Start`（暂停页 `A` / `B` 也算继续） |
| 选模式 · 结算页继续 | `A` / `Start`（模式页 `A` 选单人、`B` 选双人） |

只插一把手柄也能玩，两人共用移动方向。

**指南只显示当前在用的那套**：敲键盘就显示键盘图，动手柄就显示手柄图，两者不会同时出现。

## 机制

- **单双人模式**：进场先选。单人时玩家二不存在，HUD 上那一条整块收起。
- **连续血条**：气血是一根渐变的条，不再是一格一格的方块；掉到四分之一以下转成红色。
- **三连击**：连按攻击键出三段，第三段伤害更高、范围更大、击退更远。
- **动作按武器分流**：斧与锤走劈砍，叉、匕、璋走突刺，剑与空手走基础挥砍——三种动作各有一套帧图。
- **单手一把**：手上只拿一把，没有备用格。
  - 空手捡起直接上手；手上有别的就换手，换下来的那把落回原地。
  - `E` 丢掉手上那把，回到空手。
  - `R` 交给队友，两人相距 160 像素内才递得过去；队友手上有武器时两人对换。
- **同款不叠**：手上已有同一种武器，地上的那把就不捡，飘字「同款武器，先扔掉」。
- **武器耐久**：每种武器挥够次数会碎，碎后变成**空手**，伤害只有 0.5，必须去捡。
- **掉落池 11 种**：骨牙匕（最快、耐久 16）｜玉璋刃（初始，耐久 40）｜青铜剑（伤害 2）｜青铜钺（伤害 3）｜神树锤（伤害 4、范围最大、最慢）｜三枝叉（最长）｜神鸟弓（直线箭）｜四种投掷物。
  - 普通敌人击杀有 35% 概率掉武器，武器按阵次解锁：前两阵四件基础、第三阵加钺 / 叉 / 镖、第五阵加锤 / 罐 / 铃 / 弓，池内均匀随机。
  - BOSS 必掉 3 把：青铜剑、神鸟弓、神树锤。
- **四种投掷物**：眼形石稳准、玉璋镖快而穿（穿 2 个）、陶罐雷慢炸大（引信 0.45 秒、半径 130）、青铜铃弹地一次再爆。
  - 投掷物带**弹数**而不是耐久：初始 3 发、上限 5 发。
  - 扔完脱手，落点留一枚残骸；走回去按拾取键能捡回一发。
- **两条远程路线**：弓走直线箭（速度 1180、无重力），投掷物走抛物线（重力按各自参数，200~1600 不等）。
- **宝箱**：破阵奖励，走近按拾取键开启，出武器 / 海贝 / 玉器，一次 1 件。
- **机关**：前五阵末尾各浮出一座青铜机关，一种是回满两人气血，一种是让下一阵提前到来。
- **消耗品**：海贝回气血 2 点，玉器回能量 50 点。
- **旋风斩**：命中攒能量（每次 +7），满 100 时 跳 + 攻击 同按，1.5 秒内每 0.13 秒判定一次，半径 200。
- **打队友**：挥刀能命中同伴，**不掉血**；对方手里不是玉璋刃时被震飞，换回玉璋刃——原作那个坑队友的设计。
- **前景遮挡**：五处高物立在世界坐标里，角色走到背后会淡下去，但仍看得见轮廓。
- **Boss**：器心 · 纵目之主，26 血，出手后有硬直，硬直中受伤翻倍并飘「弱点 ×2」。

### 六阵与剧情

每阵开场打一条 2.5 秒的叙事条，三行一段，用器物的口吻串成一条线：从被挖出来，到认出锈蚀的源头是自己剥下的那层壳。

| 阵 | 副题 | 体数 | 机关 |
|---|---|---|---|
| 第一阵 | 锈蚀试探 | 8 | 回血 |
| 第二阵 | 它们跑起来了 | 12 | 加速 |
| 第三阵 | 厚甲压上来 | 15 | 回血 |
| 第四阵 | 坑壁塌了 | 18 | 加速 |
| 第五阵 | 它们数着我的名字 | 21 | 回血 |
| 器心 · 纵目之主 | 锈蚀的源头 | 11 | — |

敌人四种：`walker` 铜锈俑、`fast` 疾行俑、`brute` 厚甲俑、`boss` 纵目之主。

## 素材从哪来

- 角色、敌人、背景、道具、刀光、图标，全部由 **AI 生图 + 手工后处理** 得到，不是纯代码绘制。
- 生图统一用洋红底，后处理按 `min(R,B)-G` 量化抠图并做 despill，否则边缘会留一圈紫。
- 逐帧素材按动作条带切分，再统一锚点与画布尺寸，最后压成 WebP。
- 拾取图标切完再统一到同一张正方形画布、按最长边占固定比例居中，所以地上那堆武器不会忽大忽小。
- 素材共 104 个文件、约 2.77 MB，全部随仓库离线分发，运行期零网络请求。
- 流程与脚本见 [tools/README.md](tools/README.md)，设计约束见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 角色是照着馆方原文画的

每一个五官都不是随手编的：

> 圆顶笄发，头顶浑圆，头发与面部界限分明。长脸宽颐，脸庞瘦削，宽眉大眼，眼角上挑，
> 蒜头鼻，鼻翼较宽，阔口紧闭，神情肃穆。大耳外张，耳垂各有一穿孔，可能用于悬挂耳环
> 之类的装饰品。颈较粗，颈下端前呈倒尖角形，后呈圆弧形。头顶后方有一方孔，其下有"U"形轮廓。

出处：**《吉金万里 重点文物说明（20260929）》**，东莞市博物馆提供。

对应到代码里：

| 原文 | 实现 |
|---|---|
| 圆顶笄发 | 头顶浑圆，横插一根笄，两端露出圆头 |
| 长脸宽颐 | 竖向椭圆脸，非圆脸 |
| 宽眉大眼，眼角上挑 | 粗眉紧压眼上，杏仁眼、外眼角上扬 |
| 蒜头鼻，鼻翼较宽 | 球状鼻头 + 双鼻孔 |
| 阔口紧闭 | 一条厚横线，加下唇高光 |
| 大耳外张，耳垂穿孔 | 两侧外展耳廓，耳垂各一个小黑孔 |
| 颈较粗，下端前呈倒尖角形 | 梯形颈，前端收成倒三角 |
| 头顶后方方孔、"U"形轮廓 | 头顶后方的方形刻线 |

**艺术处理部分**：双刃武器、锈蚀怪物、波次数值、旋风斩、武器耐久、投掷物、宝箱与机关，以及青铜神树与太阳轮的场景化呈现，都是为游戏性服务的再创作，**不是考古复原**。

## 技术

- 单页应用：一个 `index.html` + 八个脚本模块 + 素材目录，`file://` 直接打开即可运行。
- 零依赖：无 CDN、无 npm、无外部字体；脚本全部 IIFE 挂 `window.*`，不用 ES module（`file://` 下会被 CORS 拦）。
- Canvas 2D 逐帧绘制，角色显示高度 252px，12 个动作共 43 帧；敌人 4 类共 14 帧。
- 四层视差：远景 0.20 / 中景 0.50 / 地面 1.00 / 前景 1.00。
- 三级降级：素材缺失时逐级回退（帧图 → 单图变换 → 纯代码矢量绘制），任何情况下不白屏。
- 音效与背景音乐全部由 Web Audio API 实时合成，零音频文件、无版权素材。打击音按武器材质分流（玉 / 骨 / 青铜 / 锤 / 陶 / 铃），低频尾长跟随顿帧；背景音乐分 drone、节奏、氛围三层，随六阵升档，血量见底时低通下压、BOSS 硬直时自动让位。`M` 键静音。
- 手柄走 Gamepad API 轮询，支持双人双柄。
- 1600×900 逻辑分辨率，按窗口等比缩放；世界宽 3400，地面线 706。

## 已知边界

这是**参赛 demo**，不是商业成品：

- 六阵，逐阵加量，末阵是器心 · 纵目之主带一群随从。
- 没有坐骑（原作有野猪、老虎）。
- 无存档、无联机、无关卡选择。
