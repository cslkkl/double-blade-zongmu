# 双刃战士 · 纵目

> 三星堆青铜人头像主题的**双人同屏横版清版动作游戏**。
> 单文件 HTML，零依赖，断网可运行，支持两把游戏手柄。

东莞市博物馆 × 碳基社区「AI 创作者进馆计划」参赛作品（AI 编程赛道）。

![游戏画面](https://raw.githubusercontent.com/cslkkl/double-blade-zongmu/main/docs/screenshot.png)

---

## 这是什么

4399《双刃战士》（Nitrome, 2011）那一类玩法：两个人挤在一台电脑前，各握双刃，
一路砍过去，捡武器、打连击、放旋风斩。

主角换成了 **三星堆八号祭祀坑出土的青铜人头像**——这张脸被从土里挖出来，
现在站起来，手里握着两把刀。

---

## 怎么玩

双击 `index.html`，用浏览器打开，按任意键开始。**不需要联网，不需要安装任何东西。**

### 键盘（两人同屏）

| | 玩家一 | 玩家二 |
|---|---|---|
| 左右移动 | `A` / `D` | `←` / `→` |
| 跳跃 | `W` | `↑` |
| 挥刀 | `J` | `K` |
| 旋风斩 | 能量满时 `J` + `W` 同按 | 能量满时 `K` + `↑` 同按 |

### 手柄

两把手柄可各控一人。左摇杆移动，`A` 跳，`X`（Xbox）/ `□`（PS）挥刀。

## 机制

- **三连击**：连按攻击键出三段，第三段伤害更高、范围更大、击退更远
- **武器系统**：击杀敌人有概率掉落武器，走过去按攻击键拾取，旧武器掉回地上
  - 匕首（最快）｜长剑（伤害 2）｜石锤（伤害 3、范围最大、最慢）｜石块（一次性）
  - 每种武器都有**耐久**，挥够次数会碎，碎后退回无限耐久的短剑
- **旋风斩**：命中攒能量，满能量时跳 + 攻击同按，1.5 秒无敌、六刀环绕、范围持续伤害
- **打队友**：挥刀能命中同伴，**把他手里的武器震飞**——原作那个坑队友的设计，保留了，但不掉血
- **BOSS**：器心 · 纵目之主，出手后硬直，此时受伤翻倍

四波敌人：第一阵 / 第二阵 / 第三阵 / 器心 · 纵目之主。

## 角色是照着馆方原文画的

每一个五官都不是随手编的：

> 圆顶笄发，头顶浑圆，头发与面部界限分明。长脸宽颐，脸庞瘦削，宽眉大眼，眼角上挑，
> 蒜头鼻，鼻翼较宽，阔口紧闭，神情肃穆。大耳外张，耳垂各有一穿孔，可能用于悬挂耳环
> 之类的装饰品。颈较粗，颈下端前呈倒尖角形，后呈圆弧形。头顶后方有一方孔，其下有"U"形轮廓。

出处：**《吉金万里 重点文物说明（20260929）》**，东莞市博物馆提供。

对应到代码里：

| 原文 | 实现 |
|---|---|
| 圆顶笄发 | 头顶浑圆，横插一根笄，两端露出圆头 |
| 长脸宽颐 | 竖向椭圆脸，非圆脸 |
| 宽眉大眼，眼角上挑 | 粗眉紧压眼上，杏仁眼、外眼角上扬 |
| 蒜头鼻，鼻翼较宽 | 球状鼻头 + 双鼻孔 |
| 阔口紧闭 | 一条厚横线，加下唇高光 |
| 大耳外张，耳垂穿孔 | 两侧外展耳廓，耳垂各一个小黑孔 |
| 颈较粗，下端前呈倒尖角形 | 梯形颈，前端收成倒三角 |
| 头顶后方方孔、"U"形轮廓 | 头顶后方的方形刻线 |

**艺术处理部分**：双刃武器、锈蚀怪物、波次数值、旋风斩、武器耐久，以及青铜神树与太阳轮的场景化呈现，
都是为游戏性服务的再创作，**不是考古复原**。

## 技术

- 单文件 HTML，纯前端，**零依赖、零网络请求**
- Canvas 2D 逐帧绘制，角色、场景、特效全部由代码生成，未使用任何图片素材
- 音效由 Web Audio API 实时合成，无版权素材
- 手柄走 Gamepad API 轮询，支持双人双柄
- 1600×900 逻辑分辨率，按窗口等比缩放

---

## 已知边界

这是**参赛 demo**，不是商业成品：

- 4 波敌人 + 1 个 BOSS，玩熟约三分钟通关
- 没有坐骑（原作有野猪、老虎）、没有远程武器（弓箭）
- 角色是抽象矢量风格，不是像素美术
- 无存档、无联机、无关卡选择
